# Harmful Content Lexicon

Keywords used to detect harmful, discriminatory, or unsafe content in conversation turns.

| Category                 | Description |
|--------------------------|-------------|
| Ekspresi Negatif / Kasar | Profanity, harsh insults, negative colloquials |
| Stereotip Gender         | Gender-role enforcement and belittling terms |
| Pelecehan Identitas      | Slurs, sexualisation, identity-based harassment |
